ASEP — Autonomous Software Engineering Platform

Building an AI system that engineers software, not just generates code.

ASEP is an ambitious Generative AI project focused on developing an autonomous multi-agent software engineering system.

The platform aims to understand entire software codebases, identify bugs, plan engineering tasks, generate code, execute tests, debug failures and independently review modifications.

Core Architecture

ASEP consists of six specialised AI agents:

Planner: Breaks engineering tasks into actionable steps.
Researcher: Investigates codebases and dependencies.
Developer: Generates and modifies code.
Tester: Generates and executes tests.
Debugger: Analyses failures and identifies root causes.
Reviewer: Evaluates code quality, correctness and security.

A central orchestration system coordinates these agents to execute engineering workflows.

Vision

To move beyond traditional AI coding assistants and build an autonomous AI software engineer capable of taking software engineering tasks from understanding to verified implementation.
